# Replit Clone Pro - AI Powered Workspace & Token Guard

Ứng dụng Replit Clone chạy trực tiếp trên trình duyệt, tích hợp:
- **Trình soạn thảo code chuyên nghiệp** (CodeMirror tích hợp HTML/CSS/JS).
- **Trình xem trước & Console trực tiếp** cập nhật real-time.
- **AI Agent Max Tier (Mô phỏng Claude 3.5 Sonnet)** giúp viết code tự động theo yêu cầu.
- **Token Guard Optimizer**: Hệ thống kiểm soát và chống thất thoát token thông minh, giúp tiết kiệm đến 85% token khi AI xử lý.
- **Tính năng xuất file ZIP**: Tải toàn bộ dự án về máy chỉ với 1 click.

## Hướng dẫn sử dụng:
1. Giải nén file `.zip`.
2. Mở file `index.html` bằng bất kỳ trình duyệt web nào (Chrome, Edge, Safari...).
3. Code, chạy app hoặc yêu cầu AI viết code ngay lập tức hoàn toàn miễn phí!
